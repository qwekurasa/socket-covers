# Накладки на розетку AtlasDesign

Прототипы декоративных накладок на розетку Systeme Electric AtlasDesign ATN000143 в рамке ATN000101. Накладка печатается на 3D-принтере и надевается поверх розетки.

- `index.html` — 3D-просмотр
- `files/` — STL, STEP и параметрический скрипт `socket_cover.py` (build123d)

Размеры посадки задаются в блоке `FIT` в начале скрипта.
